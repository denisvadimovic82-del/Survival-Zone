# ЗОНА v14 — разделённый проект

## Запуск
Распакуйте архив целиком. Для запуска откройте папку через локальный веб-сервер. Например, из этой папки выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`.

Для загрузки Three.js и шрифта Nunito требуется интернет-соединение.

## Структура
- `index.html` — разметка и подключение ресурсов.
- `css/style.css` — все стили.
- `js/00-early-init.js` — ранняя инициализация.
- `js/01-core-setup.js` — обработчики ошибок и начальная настройка.
- `js/02-scene-and-terrain.js` — сцена и рельеф.
- `js/03-items-and-ui.js` — предметы и интерфейс.
- `js/04-player-and-weapons.js` — игрок и оружие.
- `js/05-world-and-radar.js` — мир и радар.
- `js/06-enemies-and-state.js` — враги и состояние.
- `js/07-menu-and-saves.js` — меню и сохранения.
- `js/08-game-mechanics.js` — игровые механики.
- `js/09-animation-and-runtime.js` — анимация и игровой цикл.
- `SOURCE_original_portrait.html` — резервная копия исходного HTML.

JavaScript-файлы подключены в том же порядке, в котором их код находился в исходном HTML. Не меняйте порядок подключений без проверки зависимостей. Вертикальный режим сохранён.
